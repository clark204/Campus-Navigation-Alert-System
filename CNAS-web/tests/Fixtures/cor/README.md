# COR test fixtures

- `sample-cor.txt`: text extracted (pdftotext -layout) from a real TCC Certificate of
  Registration PDF, with the student ID and name replaced by fake values
  (Student ID 20240001, "Juan Miguel Dela Cruz S"). Layout, labels, subjects, units,
  and dates are unchanged.
- Real CORs are generated by dompdf 3.x, A4, 1 page, with the COR printed twice.
- The QR code ("Scan to Verify") must NOT be used for validation.
- Never commit a real student's COR PDF here.
- `sample-cor-smalot.txt`: the exact text smalot/pdfparser extracts from a real TCC COR PDF
  (fake ID and name). Note that subjects with a single schedule row come out with the
  units glued to the day, e.g. "IT 120 BSIT3B 3Fri 07:00-10:00 AM", and labels can be
  tab-separated ("Student ID: 20240001\tAY: 2026-2027 1st"). The parser must handle this.
- `sample-cor-2025-2nd-term-smalot.txt`: smalot/pdfparser text from a real COR of an
  OLDER layout (AY 2025-2026 2nd Term), with fake ID, name, and registrar name. Differences:
  - Table header says "Subject" (not "Course"); course codes can be all caps words ("PATH FIT 4")
  - Section has a space: "BSIT 2B"
  - Each extra schedule line repeats the course and section WITHOUT units:
    "IT 112 BSIT 2B 3 THU ..." then "IT 112 BSIT 2B\tTUE ..." (count units once per course)
  - Days are uppercase or combined: THU, MW, TTH; times look like "04:00 PM 07:00 PM"
  - AY looks like "2025-2026 2nd Term"; Program includes the year level: "BSIT 2nd"
  - Date Enrolled is numeric: "01/07/2026" (MM/DD/YYYY)
  - Includes the registrar's name and a fuller Statement of Account
  Both layouts must parse: 9 subjects / 26 units here, program BSIT, college C01.
